# Odin3：游戏内 Android 软键盘

2026-10-11，`feature/malos/swan-xr-ahb`，基线 `cee4b8ee`。
用户报告 MHR 已能启动，但角色命名时无法打开 Android 键盘。

## 原因与修改

主屏幕的快捷菜单「键盘」及触摸手势仅调用 `toggleSoftInput(SHOW_FORCED)`，
没有把焦点交给文本编辑 View。已有 `IMEInputReceiver` 仅在外接屏分支使用。
Odin3 的 `dumpsys input_method` 显示 served view 是 `AndroidComposeView`，
`inputType=0`、`mServedInputConnection=null`，因此缺少向游戏提交文字的输入连接。

- 主屏幕、外接屏、快捷菜单、触摸手势及输入绑定统一使用 `IMEInputReceiver`。
- 显式请求编辑焦点，等窗口获得焦点后建立输入连接并显示 IME；不再依赖全局 toggle 或固定 500 ms 延迟。
- 打字期间不允许异步指针捕获回调抢走编辑焦点；关闭/卸载取消待执行显示请求，旧连接不能向新会话注入文字。
- ASCII 大写和符号使用已有虚拟键盘路径保留 Shift；退格、向后删除及编辑器确认直接传给 guest。
- 组合文本在本地缓存，最终提交时才派发，避免逐次候选更新产生重复文字；不记录用户输入内容。

本次不增加自动检测 Windows 文本框的协议，也不扩充原有字符映射；中文等非 ASCII
文本输入仍不在本次验收范围。游戏请求输入时，通过应用快捷菜单的「键盘」主动打开。
未改游戏、存档、驱动、shader cache 或 Foundation。
